The Modus themes is created by [Prot](https://protesilaos.com/). I love its aesthetic and use it almost everywhere.

-   Blog: I created the [hugo-modus](https://github.com/goofansu/hugo-modus) theme for this blog.
-   Emacs: The original [modus-themes](https://protesilaos.com/emacs/modus-themes) package.
-   Ghostty: The [config](https://github.com/goofansu/nix-config/blob/5a65def144426b08dbf747b3bf0e55b9b553c6d9/term.nix#L79-L96) is transformed from the [DIY Range of color with terminal emulators](https://protesilaos.com/emacs/modus-themes#h:6b8211b0-d11b-4c00-9543-4685ec3b742f) section.
-   Pi coding agent: I generated [two themes](https://github.com/goofansu/pi-stuff/tree/main/themes) using the colors of modus-vivendi and modus-vivendi-tinted with the help of Claude.
-   Zed: The [modus-themes](https://zed.dev/extensions/modus-themes) extension created by [Vitaly Slobodin](https://bsky.app/profile/did:plc:5rc3vpldcyehjjqkj2qmdwvo).
