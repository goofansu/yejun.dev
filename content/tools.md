## Software {#software}

-   [Alfred](https://alfred.app/) is the swiss army knife on macOS
-   [Emacs](https://www.gnu.org/software/emacs/emacs.html) is the major software for [coding, reading and writing](https://github.com/goofansu/emacs-config/blob/f79f654402526bb06618dcf84825803aa3997cf2/init.el#L22-L25)
-   [Zed](https://zed.dev/) is helpful when reviewing the results of [agentic coding]({{< relref "agentic-coding" >}})
-   [Ghostty](https://ghostty.org/) is the best terminal emulator I've ever used on macOS
-   [Zotero](https://zotero.org/) and [zotero-better-bibtex](https://retorque.re/zotero-better-bibtex/) generate [reference.bib](https://github.com/goofansu/emacs-config/blob/f79f654402526bb06618dcf84825803aa3997cf2/modules/init-reading.el#L1) automatically
-   [Calibre](https://calibre-ebook.com/) for reading EPUBs


## Services {#services}

-   [Bitwarden](https://bitwarden.com) for passwords ($10/year)
-   [Raindrop](https://raindrop.io) for bookmarks (free)
-   [Google Drive](https://drive.google.com/) for photos ($29.99/year)
-   [Claude Code](https://www.claude.com/product/claude-code) for coding ($20/month)
-   [Amp](https://ampcode.com/) when Claude Code is rate-limited (prepaid)
-   [Vercel](https://vercel.com/) for hosting static websites (free)
