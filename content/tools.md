## Software {#software}

I choose software with two principles:

1.  Data remains accessible and usable even when the software used to create it is no longer available.
2.  The software should integrate seamlessly into my workflow.

With the principles, I prefer open source software to proprietary ones:

-   [Emacs](https://github.com/emacs-mirror/emacs) with programming/writing/reading
-   [Ghostty](https://github.com/ghostty-org/ghostty) with [pi](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent)/[fish](https://github.com/fish-shell/fish-shell)/[tmux](https://github.com/tmux/tmux)/[neovim](https://github.com/neovim/neovim) for [agentic coding]({{< relref "agentic-coding" >}}) in TUI
-   [Zed](https://github.com/zed-industries/zed) for agentic coding in GUI
-   [Zen](https://github.com/zen-browser/desktop) for web browsing
